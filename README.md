## 📌 스터디 소개

이 저장소는 Kubernetes를 **강의 수강 & 실습 → 내용 정리 → 문제 풀이 → 복습**의 흐름으로 학습하기 위한 스터디 저장소입니다.

각 스터디원은 매주 지정된 강의를 수강한 뒤,
학습한 내용을 자유롭게 정리하여 GitHub README 형태로 PR을 올립니다.

또한 기존의 발표자 중심 진행 방식 대신,
매주 한 명의 스터디원이 Kubernetes 관련 문제를 직접 준비하고
스터디 시간에 함께 문제를 풀고 풀이를 공유하는 방식으로 진행합니다.

단순히 강의를 시청하는 것에 그치지 않고,
직접 내용을 정리하고 아키텍처를 그려보며 문제를 통해 개념을 확인하는 것을 목표로 합니다.

## ✅ 스터디 참여 규칙 요약

### 👥 모든 스터디원(출제자 포함)

스터디 시작 전까지 아래 작업을 완료합니다.

```text
1. 해당 주차 강의 수강 & 실습 진행
2. 학습 내용 README 정리
3. 강의에 등장한 아키텍처 직접 작성
4. GitHub PR 제출
```

### 📝 문제 출제자

스터디 시작 전까지 아래 작업을 준비합니다.

```text
1. Kubernetes 관련 문제 최소 5문제 준비
2. 문제 정답 준비
3. 문제 풀이 및 설명 준비
```

스터디 종료 후에는 아래 작업을 완료합니다.

```text
1. 문제 정리
2. 정답 및 풀이 작성
3. GitHub Issue에 최종 업로드
```

## 🚀 목표

이 스터디의 목표는 Kubernetes 개념을 단순히 읽고 암기하는 것이 아니라,  
**직접 정리하고, 구조를 그려보고, 실습하고, 문제를 풀면서 실제로 이해하는 것**입니다.

최종적으로는 Kubernetes의 주요 개념과 동작 구조를 이해하고,  
실제 환경에서 활용할 수 있는 수준까지 학습하는 것을 목표로 합니다.
